Sistem Monitoring Drill Bit

Sistem informasi inventaris berbasis web yang mengintegrasikan divisi Produksi CNC dan Grinding secara real-time.

Peran: System Analyst & Web Developer
Metode: Waterfall & Black Box Testing
PHPMySQLUMLXAMPP

Latar Belakang Masalah

Pengelolaan stok dan kondisi drill bit di PT Dawee CNC sebelumnya dilakukan secara manual menggunakan buku log fisik. Hal ini menyebabkan:

  • Rentan terhadap human error.
  • Informasi stok tidak real-time.
  • Sering terjadi downtime mesin akibat alat habis mendadak.

Solusi & Hasil

Saya merancang aplikasi web terpusat dengan database MySQL untuk mendigitalisasi seluruh pencatatan.

  • Dashboard Real-time: Memantau ketersediaan alat (Baru, Re-grind, Scrap).
  • Otomatisasi Laporan: Cetak laporan PDF berdasarkan filter tanggal.
  • Integrasi Divisi: Menghubungkan operator CNC dengan tim Grinding.
